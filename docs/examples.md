# Examples

Seven runnable scenarios, from one vault and one agent up to every memory type in one topology. Each folder has its code, its data and a README that walks through it.

--8<-- "README.md:examples"

Each folder installs with `pip install -r requirements.txt`. Examples 01 to 06 call an LLM, so their READMEs say which provider and key to set; example 07 needs none. [Example 07](https://github.com/Filippo-Venturini/ctxvault/tree/main/examples/07-full-memory-topology) is the dataset behind the [live demo](demo.html): run it, then `ctxvault ui` from its folder to see the same memory live.
